# Mini Duck Lite V0.1 产品范围

本文档是 `Mini_Duck_Lite_V0.1_PRD.docx` 的工程执行摘要。原始 Word 文档用于产品评审；仓库内文档用于开发和接力。

## 产品定义

Mini Duck Lite 是一只无需持续遥控，能自主站立、双足移动、摔倒后自行恢复，并能通过视觉发现人后主动走近的小型机器人。

V0.1 的连续 Hero Demo：

1. 开机并进入安全站立；
2. 发现前方的人并调整朝向；
3. 双足走近 1～2 m，在安全距离停止；
4. 被轻推倒后识别跌倒；
5. 自动恢复站立并继续行为流程。

## V0.1 必须包含

- 10DOF 双腿机械模型，每条腿包含 hip yaw/roll/pitch、knee pitch、ankle pitch；
- MuJoCo 仿真与 PPO 行走 policy；
- 至少一种 recovery policy；
- ONNX 导出和 CPU/真机推理；
- 低成本总线舵机、IMU、RGB 摄像头；
- 人体检测、高层状态机、50 Hz runtime；
- 安全限幅、急停和日志指标。

## 明确不做

- 把持续遥控作为核心交互；
- 隐藏轮替代真双足；
- LLM 对话、手机 App、云服务；
- 自研主控板或自研舵机；
- 高精度 SLAM 和多房间导航；
- V0.1 商业化。

## 软件验收摘要

- 模型加载无警告，关节顺序、范围、方向和单位有自动化检查；
- 控制循环目标 50 Hz，长时间运行不持续 miss deadline；
- walk/recovery 训练必须先 smoke，再长训练；
- policy 可导出 ONNX，并在 CPU MuJoCo 中重放；
- 真机发生失联、NaN 或超限时进入 safe state；
- 每个 Gate 都有可复现命令、commit、配置和结果记录。

## 预算和硬件边界

G0/G1 使用现有电脑，预算为 ¥0。只有软件闭环通过后，G2 才采购 2 个舵机、总线板、IMU 和必要电源小件。V0.1 真机预算目标为 ¥2,000～3,000，具体型号和参数必须在采购前重新核价并实测。
