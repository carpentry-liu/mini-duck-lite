# 轮滑障碍秀：物理量可视化设计

日期：2026-09-02。证据等级：**SIM**。对象仍是上游 Microduck 14DOF roller 模型，不代表规划中的 10DOF 真机，也不构成 HIL 或 REAL 证据。

## 目标

保留 `roller-fast-carve-v1` 的纯净回放，额外生成一套用于观察控制与接触过程的物理分析证据：

- 物理分析视频：在同一条确定性仿真轨迹上叠加关节、接触、力和力矩信息；
- 逐控制步遥测：保存可复查的原始数值和单位；
- 交互回放页：点击代表性关节后，切换该关节的六维传递力/力矩时域曲线；
- 机器可读清单：记录模型、策略、采样率、字段口径与派生图层，避免只凭视频判断。

MP4 本身不能点击，因此视频按时间自动轮播代表性关节；点击查看只存在于交互回放页中。

## 原始物理量与口径

| 画面/字段 | MuJoCo 来源 | 单位 | 说明 |
|---|---|---:|---|
| 关节位移 | `qpos - qpos_reference` | rad | 以回放初始化姿态为零点 |
| 关节速度 | `qvel` | rad/s | 对应关节自由度 |
| 驱动力矩 | `qfrc_actuator` | N·m | 执行器映射到广义坐标后的实际驱动力矩 |
| 惯性力矩 | `M(q) qacc`，由 `mj_mulM` 计算 | N·m | 仅用于关节转动自由度；与驱动力矩分层显示 |
| 约束力矩 | `qfrc_constraint` | N·m | 接触及其他约束映射到关节自由度的广义力 |
| 关节六维传递量 | `mj_rnePostConstraint` 后的子刚体 `cfrc_int`，力矩平移到关节 anchor | N / N·m | `Fx/Fy/Fz` 与 `Tx/Ty/Tz`；原点是关节 anchor，XYZ 轴与世界坐标系一致，不是测力传感器实测值 |
| 接触六维力 | `mj_contactForce` | N / N·m | 从接触坐标系变换到世界坐标系后保存 |
| 接触位置 | `contact.pos` | m | 用于接触点与热力图定位 |

所有数据按策略控制频率 50 Hz 保存；MuJoCo 内部仍以 0.005 s 步长积分。

2026-09-05 发布修正（v1.1.1）：旧版直接显示 `cfrc_int[:3]`，其力矩原点实际是所在运动树的质心，会与关节位置的力矩不同。现在使用 `tau_anchor = tau_com + (subtree_com[body_rootid] - xanchor) × force`，保留世界坐标轴。遥测 schema `1.1.0` 明确写入 `wrench_origin=joint_anchor`、`wrench_axes=world`；每个关节记录动态 `wrench_origin_m`，CSV 同时保存其 XYZ 坐标。历史补丁 `0003` 不变，新补丁 `0004` 修正采集器、展示口径并增加与 MuJoCo 关节原点 force/torque sensor 的对照测试。

例如质量 1 kg、质心距铰链 0.5 m 的水平静态梁，旧值为 `[0, 0, 0] N·m`，关节原点力矩为 `[0, -4.905, 0] N·m`。修正后的值与 MuJoCo torque sensor 一致，并覆盖旋转 90° 后的世界坐标轴转换。参考 [MuJoCo c-frame 定义](https://mujoco.readthedocs.io/en/stable/APIreference/APItypes.html#c-frame-variables)。

## 派生可视化

以下图层不是 MuJoCo 直接给出的连续场，必须在画面上标记为 `DERIVED`：

1. **摩擦力场**：把每个有效接触点的切向摩擦力投影到地面，在邻域内做带符号的高斯插值，以红—蓝渐变显示；原始接触向量和数值仍保存在遥测中。
2. **动态对数力箭头**：箭头方向取真实接触力方向，显示长度使用 `log1p(|F| / F_ref)`，避免大力完全遮住小力；箭头旁同时显示真实牛顿值。
3. **扭矩涡旋**：以关节驱动力矩的符号决定旋向、以对数幅值决定半径和亮度。它是扭矩 glyph，不表示连续介质中的真实流场。
4. **接触热力图**：按法向接触力在接触点附近进行径向衰减，用于定位载荷集中区域。

## 代表性关节

运行时从模型中按结构选择头部、左右髋、左右膝/踝以及左右被动轮关节；若名称与模型版本不匹配，脚本根据可用的铰链关节退化选择并把最终清单写入 manifest。视频每 2.5 秒自动切换焦点，交互页允许直接点击关节列表。

## 画面布局

- 左侧：MuJoCo 回放、当前阶段、接触点、力箭头、关节扭矩涡旋和激活热力图；
- 右上：当前关节的位移、姿态、速度、驱动力矩、惯性力矩和约束力矩；
- 右中：当前关节 `Fx/Fy/Fz`；
- 右下：当前关节 `Tx/Ty/Tz`；
- 底部：接触/摩擦场、图层图例、时间与派生量声明。

纯净版和物理分析版并列发布，物理分析图层不得覆盖或替换原始验收视频。

## 验证条件

1. 相同 seed、策略与路线下重新运行，原固定路线摘要仍通过；
2. 遥测行数与控制步数一致，时间严格单调；
3. 所有字段有限，代表性关节均有完整的六维曲线；
4. 至少出现一次有效接触并产生非零法向力、切向力和关节驱动力矩；
5. 分析视频帧率为 50 fps，时长与遥测末尾时间一致；
6. 交互页离线可打开，点击不同关节会更新六维曲线与当前值。

## 限制

- `cfrc_int` 是模型中的空间传递力，受刚体、接触和执行器建模精度限制；
- 当前视觉层用于解释 SIM 过程，不能替代真机六维力传感器、力矩传感器或足底压力阵列；
- 14DOF 仿真中的量纲与趋势不能直接作为 10DOF 真机的控制增益或硬件选型结论。
